# Portfolio
Portfolio of undergrad code.
CS210 7-3 is an item tracker application written in C++. The code opens a file and reads a list of items in the in the file. The code saves the information read from the file to be later displayed in the format "name number" indicating the name of the item read and the number of times that item was read in the file. The file I open and read was "CS210_Project_Three_Input_file.txt" but any file that lists different items could be used. "ItemTracker.cpp" contains functions to read data from file, creates a data file, and creates the functionality of the menus in main. main holds a menu intended to take user input to display desired functions. "ItemTracker.h" holds the helper, constructor, backup output, and menu functions. 

This project is intended to help a grocery store that is wanting to remodel their produce area and wanted information of how frequently they sold different produce items. They would then take this information and designate more space to the produce that sold the most and less space to the lower selling items. The code is great at reading and outputting the information read from the file, but the formatting of the file needs to be correct. Some failsafe coding could be added to the code to insure no bugs or errors. 

I found the opening, reading, and closing of files to be the most difficult part of this project. Our ZyBooks assignments helped a little, but I was confused when I was going through the assignments. I looked into YouTube tutorials to help me out. The auto fill on Visual Studio was also very nice, but I had to be careful with it because sometimes it was wanting to auto fill code that was slightly different to the code I was wanting to write.

I know that file manipulation in coding is very important when I move into bigger projects later in my career. Breaking through this wall was something that I would have to have done sooner or later so I am happy to say that I have begun to master this skill. I am not 100% yet, but I'm sure I will get there with practice.

I made this program maintainable by leaving detailed in line comments so that future coders can read what my intentions where for each portion of the code. I made this program readable by separating the code into three individual files (ItemTracker.h, ItemTracker.cpp, main.cpp) per industry standards. The program is adaptable because it is broken down into different functions. A feature can be added by simply adding another function.
